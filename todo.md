# tiling-verified todo

1. Extend the finite-axiomatisation theorem to substitute over the level index n as well as formula variables, eliminating n from the meta-language so the calculus is generated by a finite set of carriers (no parametric n) plus formula-substitution + level-substitution + MP + Nec.  Currently [AxBoxK_carrier n], [AxLoeb_carrier n] etc. parameterize over n at the meta-level rather than the object-level.
2. Prove Kalmár's lemma in a hypothesis-style classical propositional calculus and derive Kalmár completeness: for every box-free classically-valid formula phi, ProvableProp phi.
